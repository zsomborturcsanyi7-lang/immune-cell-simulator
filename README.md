# immune-cell-simulator

Agent-based T-cell simulation framework using Mesa.

## 📌 Overview & Purpose
Simulates interactions between immune cells and pathogens in a computational agent-based model.

## ⚙️ Tech Stack & Architecture
- Python, Mesa, Matplotlib

## 🚀 Installation & Quickstart
```bash
git clone https://github.com/zsomborturcsanyi7-lang/immune-cell-simulator.git
cd immune-cell-simulator
python run_simulation.py
```
